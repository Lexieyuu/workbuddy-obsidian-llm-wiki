# CodeBuddy 官方 Skills 格式说明摘要

## 核心摘要

WorkBuddy/CodeBuddy 的项目级 Skill 使用 `.codebuddy/skills/技能名/SKILL.md` 结构。`SKILL.md` 可以通过 YAML Frontmatter 声明名称、描述和允许使用的工具，正文负责描述具体工作流。
